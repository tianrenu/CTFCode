# CTFCode Windows 便携测试版

本包包含从源码编译的独立 OpenCode `2.3.0-ctfcode.2`、CTF 定制插件与运行控制、Python、Strata Control、32K/64K native engine 和分析依赖。不是只有原版 CLI，也不要求安装全局 Python/Bun/npm。

## 使用

1. 解压整个 `CTFCode` 目录到自己可写的 SSD 目录，保持目录结构，不要只拖出 BAT 或 EXE。
2. 模型权重仍需单独下载：[模型下载与校验](https://github.com/tianrenu/CTFCode/blob/dev/docs/模型下载与校验.md)。只需 IQ1_M 两个分片。也可以复用已有完整模型目录，原地使用，不搬动、不复制。
3. 双击带项目图标的 **`CTFCode.exe`**，进入TUI开始页，依次配置模型、准备pack、打开题目和启动做题。准备与日志都在界面内，不必输入PowerShell命令。`/ctf setup` 可重开开始页，`/cd` 换题；原3/7号BAT仅保留兼容。
4. `/ctf stop` 停止任务并卸载模型但保留TUI；`/exit` 归档并退出。**`7_自检.bat`** 是外部只读状态入口，输入 `S` 会关闭本包会话并卸载模型，不影响其他应用。

只有两个GGUF、没有pack时，先在开始页确认“校验分片并准备模型”；已有完整目录跳过。`/ctf progress` 看校验百分比和日志，`/ctf stop` 可取消并保留部分文件。需要至少16GiB可用RAM和充足SSD空间。

以下仅为开发/排障备用命令，普通用户无需执行。包根目录PowerShell中，将示例模型路径换成实际路径：

```powershell
& '.\本地模型配置与日志\Strata验证\runtime\control-0.1.52\python\python.exe' -I -X utf8 '.\bootstrap.py' setup --model 'D:\CTF模型\GSQ-RCO-Coder' --prepare
```

该步骤完整校验分片并准备pack，不加载推理模型，不另下载权重。模型、引擎的下载地址和校验值同时放在包内 `文档/` 与 `config/`，也可在线查阅。另一台干净电脑的首次完整pack准备尚未实测，不声称自动安装全流程已经通过。

使用自带 Python 时，完整路径由包自动定位；不应修改源码中的个人路径。已有模型目录位置保存在本包 `local.json`，不需要手改 JSON；移动包后插件 URI、解释器和启动参数会重新生成。

默认 32K，64K 仍是显式候选。保留 16GiB 可用 RAM 加载门禁、1792MiB 显存预留、14GiB 工作集/100ms 守护、单模型及 CLI 进程树限制；不承诺任意应用负载下能加载或恒定 10+ token/s。

## 已带入的定制

- CTF Agent 配置、普通分析操作权限、精简工具说明。
- 原始线索/证据索引、脚本执行与产物读回状态、错误和停止提示。
- 自动日期前缀处理、64K 压缩与缓存适配。
- 32K/64K 独立引擎选择、资源保护、取消/停止/退出清理和独立会话环境。
- 启动、`/cd`、重开同目录和 `/new` 都是空白新会话；旧记录在原工作目录的 `.ctfcode/会话归档`，每会话独立保存，不能自动恢复模型上下文。附件、脚本和解题成果不删除。

权限匹配不是操作系统沙箱。只使用可信的授权题目副本；未知 PE 在虚拟机或受限仿真中分析，不直接执行。不要以“不弹确认”为理由执行不明脚本。

## 许可与验收边界

OpenCode 与 Strata 的许可见 `licenses/`；Python 及依赖许可保留在其目录。包内 NVIDIA CUDA/cuBLAS 组件受 `licenses/NVIDIA-CUDA-EULA.html` 约束，需要兼容 NVIDIA 驱动。模型不在包内，另遵守模型许可。

`bundle-files.json` 记录固定发布文件的 SHA256。源码 ZIP 不包含便携二进制，用户应下载 Release 的 **windows-x64 便携包**。

这是便携测试版，不代表所有硬件或干净机器的端到端验收已经通过。具体通过项、跳过项及未完成项以对应 Release 验收说明为准；不能直接借用旧工具箱测试结论。
