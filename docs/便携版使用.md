# Windows 便携测试版：不用自己拼装

[下载 v0.1.0-preview.2](https://github.com/tianrenu/CTFCode/releases/tag/v0.1.0-preview.2)

## 下哪个包？

下载 **`CTFCode-v0.1.0-preview.2-windows-x64.zip`**，不是 GitHub 自动提供的 Source code。压缩包约 1.43GB，解压约 2.37GB，已经包含：

- OpenCode CLI 1.2.26 与完整 CTF 配置/插件。
- 单模型启停、独立会话、状态显示、资源守护和 Windows 进程树限制。
- 32K 默认/64K 候选切换、日期前缀处理、自动压缩与缓存适配。
- Python、Strata Control、两档 CUDA 13 native engine，以及固定版本的插件依赖。
- `pefile`、Capstone、Unicorn 及其许可；Unicorn 对应版本源代码随包保留。

**不需要额外安装原版 OpenCode、Python、Bun 或 npm。不包含模型权重或模型 packs。**

## 只需要这样用

1. 将整个包解压到自己的可写 SSD 目录，保持内部目录结构。
2. 准备模型：[IQ1_M 两个分片下载与校验](模型下载与校验.md)，合计约 58.4GB。已有模型可直接复用，不移动或复制。
3. 双击包里的 **`3_CTF做题界面.bat`**，首次输入模型目录（内部有 `IQ1_M` 子目录）。缺少 pack 时会先校验权重并准备 pack；随后选择授权题目副本及 32/64 档。
4. 用 **`7_自检.bat`** 看真实运行状态，输入 `S` 请求停止本包的会话；TUI 中 `/exit` 正常退出并释放本轮资源。

不要只运行 `程序/opencode.exe`：那会绕过 CTF 运行控制和插件注入。不要把模型目录、程序目录、盘根或用户主目录当作题目工作区。

自己的模型位置保存在包内 `local.json`，由入口生成，不需要编辑 JSON。换一个解压目录后，解释器、插件 URI 和启动参数会按新位置重新生成。不要把本机 `local.json`、会话或缓存再次打包上传。

## 硬件与资源

本版面向与参考机器相近的 Windows x64 + NVIDIA 消费显卡环境：参考为 8GB RTX 5060 Laptop、32GB RAM、20 核 CPU。需要兼容的 NVIDIA 驱动（0.1.59 manifest 最低 `580.65`）及充足 SSD 空间。

保留 16GiB 可用 RAM 加载门禁、1792MiB 显存预留、14GiB 工作集与 100ms 守护等保护，不会自动关掉你的应用。默认 32K；64K 是显式候选，不承诺任意后台负载下稳定或恒定 `10+ token/s`。

## 开发者如何复现构建？

定制源码位于 `portable/`，白名单构建器为 `script/portable.py`。它核验固定 CLI/Control 压缩包、npm integrity、Python wheel SHA256 和引擎 manifest 文件，再组装包；不会递归压缩旧工具箱。

构建需要指定已下载并核验的组件缓存和两档引擎目录；命令帮助用 `python script/portable.py --help` 查看。组件仅进入 Release，不提交到 Git。源码和二进制依赖仍受各自许可证约束，见包内 `licenses/`。
