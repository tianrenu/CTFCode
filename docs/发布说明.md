日期：2026-11-16。对外入口改为带项目图标、版本信息和普通用户权限清单的 `CTFCode.exe`，不是将原版OpenCode改名，也不是新增一套桌面或Web做题台。小型入口复用同一包内Python、控制器和定制OpenCode TUI。

- 打开即显示“配置模型 → 校验/准备pack → 打开题目 → 启动”的原生开始页；`/ctf setup` 重开，原3/7号BAT仅保留兼容。

- 启动器源码、图标、普通用户权限manifest与构建SHA随包提供。Windows 10/11自带.NET Framework 4.x即可运行，无需另装SDK；当前无代码签名，不要求用户绕过安全警告。

回归：Python60通过/2跳过，Node46通过/1跳过；已从真实便携布局启动EXE并看到原生开始页和指南，正常退出0。

本轮是入口与首次配置体验整改，不是新的GPU测速或CTF解题能力验收。另一台干净电脑的完整58.4GB首次pack准备、近满64K长期稳定性仍未验证；不得把受控失败/取消或已有模型复用当作这些成功证明。

## 下载包怎么用

Release 中的 `CTFCode-v0.1.0-preview.1-source.zip` 是源码包；旁边的 `SHA256SUMS.txt` 和 `CTFCode-v0.1.0-preview.1-manifest.json` 用于校验与检查包内容。解压后先阅读根目录 `README.md`，再按 `docs/README.md` 下载第三方资源。

不要在源码包里寻找模型或安装器，不要直接执行未知赛题附件。模型、Strata、CUDA 运行库的许可独立于本仓库，须分别遵守。
