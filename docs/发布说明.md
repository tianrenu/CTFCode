# v0.1.0-preview.1：源码与部署指南预览

这是 CTFCode 的首个**源码/文档预览版**，不是可执行安装包，也不是完整优化工具箱的迁移完成版。

> **发布范围纠正：本包缺少现有 CTF 定制层，不能复现作者当前使用的优化版工具箱。** 原版 OpenCode 下载步骤仅用于基础连接测试，不是最终安装方案。详见[定制层迁移状态](定制层迁移状态.md)。此纠正不意味着运行代码已经迁移完成；已发布的版本标签、源码包和校验值保持不变。

## 本版包含

- OpenCode `v1.2.26` 源码快照，来源提交 `d954026dd855e018302a6c0733a1dd74140931df`，保留原作者署名、目录和 MIT 许可证。
- [中文部署指南](README.md)：模型和 Strata Control/native engine 的精确版本、下载链接、文件大小、SHA256，以及准备 pack、独立 CLI 连接和故障排查步骤。
- [公开配置示例](../config/opencode.example.json)：只连接本地 `127.0.0.1:18791`，不改桌面版；示例默认对命令和修改保留人工确认。
- 模型与引擎的机器可读下载清单。

当前 GitHub 项目从这一上游快照建立独立初始提交，不携带完整的上游 Git 历史；这不改变原源码的归属。完整历史见 [OpenCode 上游](https://github.com/anomalyco/opencode)。

## 本版不包含

- 模型权重、生成的 packs、Strata/OpenCode/Python 二进制和运行依赖缓存。
- 作者本机的整合材料、绝对路径配置、赛题附件、解题成果、会话、原始测试日志和凭据。
- 已全部移植的 32K/64K 生命周期、工作集守护、缓存/上下文插件及模型管理 TUI。
- 自动安装器或已构建的 `CTFCode.exe`。

**作者现有工具箱的验收结果，不能当成本仓库预览包的运行验收结果。** 请从[部署指南](README.md)了解手动接入步骤；暂不应把本版当作比赛期间可直接替换现有环境的工具。

## 已做与未做的检查

本版公开文档/清单已检查 JSON 语法、PowerShell 代码块语法、本地文档链接、下载表与来源记录的一致性，以及作者本机路径和敏感数据泄漏。发布时另核对 Git 跟踪文件清单、压缩包内容和 SHA256。

未安装完整 Bun workspace 依赖，未构建定制 CLI，也未在干净 Windows 机器上完成全流程部署。上述静态检查不是构建、解题效果或长期稳定性证明。

## 下载包怎么用

Release 中的 `CTFCode-v0.1.0-preview.1-source.zip` 是源码包；旁边的 `SHA256SUMS.txt` 和 `CTFCode-v0.1.0-preview.1-manifest.json` 用于校验与检查包内容。解压后先阅读根目录 `README.md`，再按 `docs/README.md` 下载第三方资源。

不要在源码包里寻找模型或安装器，不要直接执行未知赛题附件。模型、Strata、CUDA 运行库的许可独立于本仓库，须分别遵守。

## 发布约定

- GitHub Actions 在本项目首版仓库中禁用。上游源码自带的部署、签名和包发布工作流仅作为上游快照保留，不代表已经适配本项目。
- 只从经过审查的 Git 提交生成包，例如 `git archive --format=zip --prefix=CTFCode-v0.1.0-preview.1/ v0.1.0-preview.1`，不要直接压缩整个工作目录。
- Release 标记为 **pre-release**；无持续 `10+ token/s`、64K 与 32K 同等稳定、完整离线运行或开箱即用承诺。
- 后续版本优先移植并验收现有优化运行链，再提供新的用户入口和可执行发行包。
