# TUI整合进度

## 已确认的会话规则

1. 每次启动、打开或切换工作目录，一律新建空白会话。重新打开同一目录也不恢复旧会话，不重放旧消息、工具结果或压缩摘要。
2. `/cd` 的目标行为是“归档原目录会话 → 切换目录 → 新建会话”，不沿用上游把原会话移动到新目录的行为。
3. 离开前，旧会话保存在它原来的工作目录；新目录的记录独立保存，不覆盖、不混入其他题目的会话。
4. 归档提供可阅读文本和完整结构化记录，供用户查看、复制并自行组织新的提示词；不能作为模型启动时自动读取的工作记忆。
5. 同一目录多轮任务各自保存独立会话标识。题目附件、用户文件和已生成脚本均保留，不因清空上下文删除。
6. 有任务正在运行时，先明确停止当前任务再切换。归档失败、目录校验失败应留在原会话并报告，不静默丢记录。
7. 此规则只作用于这套独立 CTFCode，不修改或清理用户另用的桌面 OpenCode。

## V2 配置与原生工具迁移进展（2026-11-16 本轮补充）

- `v2/settings.py` 显式映射旧配置到 V2：只启用同一个本地模型，32K/64K 的软窗口、4096 输出、步数、超时及自动摘要均保留；普通分析免逐条审批，高风险命令仍审批，工作区外默认拒绝。模型服务只使用 18791，8080 留给 Burp。
- `v2/ctf-server.mjs` 使用 V2 原生 Agent 循环和六个原生工具 `read/glob/grep/write/edit/shell`，没有再增加一层解题 Agent；精简工具说明，限制 read 默认120行、shell 默认120秒/最多600秒，不允许后台或无限超时。
- Python 脚本写入后复用静态语法诊断，不执行待检查源码；真实工具回归已覆盖“写错→提示→读源→修正→执行→读回”。这一流程由合成响应驱动，不是模型自行解题结果。
- 已确认 V2 原生摘要保留工具 schema 和历史前缀，未盲目移植 V1 缓存重写器。32K/64K 实际 HTTP 请求里的 system、tools 和已有消息前缀一致；摘要限制工具 token，若仍返回工具调用则立即失败、不执行、不追加重试。**这不证明真实 Strata 已命中 KV 缓存，也不是长上下文测速。**
- 自动初始日期只依据 `core/date` 来源元数据移除，保留用户自己提供的日期文字；跨午夜时追加的日期更新仍未单独验收，不能称为完整跨日验证通过。
- 启动不再因缺少词表直接使服务插件初始化失败；可以进入未配置状态，但普通请求和摘要请求均须先通过词表核验才允许发往推理服务。真实 CLI 回归确认“缺失→拒绝发送、错误哈希→拒绝发送、补齐→唯一一次成功发送”，未放宽生产哈希检查。
- 修正 Python 回归夹具的模块缓存隔离：源目录测试和迁移目录测试同进程运行时不再错误复用运行器；正反顺序均通过。

## 原生模型控制中心进展（2026-11-16 本轮补充）

- 新增 `v2/ctf-center.mjs`：在原生 TUI 用 `/ctf` 打开控制中心，可查看实时资源、选择已有模型目录、启动/停止模型、选择32K/64K、切换题目目录。操作不注册为模型工具，也不增加模型上下文中的工具 schema。
- `v2/controller.py` 通过随机认证的 loopback 通道连接插件，拒绝跨域、Host重绑定、未认证和无界请求；密钥只进入本轮独立插件配置，不进入状态文件、归档或测试报告。**这是控制通道认证，不是针对同一Windows用户/任意shell代码的OS沙箱。**
- 模型生命周期复用原 `RunLock`、`start_engine/stop_engine`、资源监控、工作集守护、引擎版本/签名及真实窗口核验；没有另造无保护加载器。加载在后台线程执行，TUI先打开；清理失败会阻止再次加载。
- `/cd` 和 `/new` 在创建原生空白会话后，将目录与会话ID同步到控制器；每会话使用独立活动目录。切换目录不重复加载模型，旧会话仍保存在原题目目录。
- 真正的模型HTTP调用新增就绪门禁：模型、会话绑定或物理窗口不匹配时不发送请求。改档位必须先结束任务、卸载、保存配置、调用 V2 原生 `location.reload`、再新建空白会话；不只修改显示数字。
- `v2/launch.py` 和既有入口的显式 `ui --native` 开发模式接通，使用已核验的2.3.0程序和 `--standalone`，隔离XDG并保留Windows CLI作业限额。不接受恢复旧会话的启动参数，不修改桌面服务。**默认3号入口和已发布便携包仍未升级，开发预览还需要明确的隔离CLI路径。**
- 配置写入中途失败会进入可见失败态并禁止加载；重新成功保存才能恢复。源码对无模型、缺失签名组件、加载期取消、重复停止、独占锁和配置写入失败提供真实文件系统/线程/HTTP回归。
