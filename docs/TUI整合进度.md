# TUI整合进度

## 已确认的会话规则

1. 每次启动、打开或切换工作目录，一律新建空白会话。重新打开同一目录也不恢复旧会话，不重放旧消息、工具结果或压缩摘要。
2. `/cd` 的目标行为是“归档原目录会话 → 切换目录 → 新建会话”，不沿用上游把原会话移动到新目录的行为。
3. 离开前，旧会话保存在它原来的工作目录；新目录的记录独立保存，不覆盖、不混入其他题目的会话。
4. 归档提供可阅读文本和完整结构化记录，供用户查看、复制并自行组织新的提示词；不能作为模型启动时自动读取的工作记忆。
5. 同一目录多轮任务各自保存独立会话标识。题目附件、用户文件和已生成脚本均保留，不因清空上下文删除。
6. 有任务正在运行时，先明确停止当前任务再切换。归档失败、目录校验失败应留在原会话并报告，不静默丢记录。
7. 此规则只作用于这套独立 CTFCode，不修改或清理用户另用的桌面 OpenCode。
8. 新会话不等于重新加载模型。切题只更换会话ID、目录和消息上下文，已加载的同一模型可以继续驻留；旧消息不能因此自动带入。

### 便携布局中发现的启动问题

- 新副本没有本机旧安装配置时，Strata曾回退执行setup、下载构建源码，并在Windows长路径处失败。新增 `v2/prepared.py`，复用官方 `adopt.plan`、Catalog和安装配置校验，为**已准备好的Coder pack**生成本轮专用运行配置；不复制模型、不下载、不运行setup、不加载模型，缺文件直接失败。
