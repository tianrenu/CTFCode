# 引擎下载与配置

[返回部署指南](README.md) · 上一步：[模型下载与校验](模型下载与校验.md) · 下一步：[首次连接与故障排查](首次连接与故障排查.md)

> 以下为手动部署参考，不是已实现的 CTFCode 自动安装器。继续使用上一章同一个 PowerShell 中的 `$Repo`、`$Data`、`$Model`、`$Cache`、`$Control` 和 `fetch`。这章不要求安装全局 Python、Bun 或 CUDA Toolkit。

## 1. 分清 Control 和 engine

[Strata 上游](https://github.com/Niko1221/Strata) 把管理程序与 native engine 分开发布。当前可复现组合是 **Control 0.1.52 + engine 0.1.52（32K）**；64K 使用 **同一 Control + engine 0.1.59** 候选。不是全部选择最新版。

## 2. 下载并完整解压 32K 基线

```powershell
$cfg = Get-Content -LiteralPath (Join-Path $Repo 'config/engines/windows-cuda13.json') -Raw -Encoding UTF8 | ConvertFrom-Json
foreach ($file in @($cfg.control, $cfg.baseline)) {
    fetch $file.url (Join-Path $Cache $file.file) $file.sha256 $file.bytes
}

# 首次安装：拒绝直接覆盖已有目录。已有安装请检查内容后复用。
if (Test-Path -LiteralPath $Control) { throw 'Control 目录已存在，请核对后复用，不要覆盖。' }
Expand-Archive -LiteralPath (Join-Path $Cache $cfg.control.file) -DestinationPath $Control

$dir = Join-Path $Data 'components32/engine/cuda13-0.1.52'
if (Test-Path -LiteralPath $dir) { throw '引擎目录已存在，请核对后复用，不要覆盖。' }
New-Item -ItemType Directory -Path $dir -Force | Out-Null
& tar.exe -xzf (Join-Path $Cache $cfg.baseline.file) -C $dir
if ($LASTEXITCODE -ne 0) { throw '引擎解压失败。' }
```

`$Control` 必须直接包含 `strata.py`、`setup.py`、`python/python.exe` 和 `bin/strata.cmd`。如果解压工具额外套了一层目录，把 `$Control` 改为实际包含这些文件的目录。**不要只复制 `strata.exe`**；引擎包内的 `engine-component.json`、DLL 和其他被 manifest 列出的文件都要保留。

复用已有且来源可信的安装时，跳过上面的解压块，先把 `$Control` 设为实际 Control 目录、`$dir` 设为实际的 `components32/engine/cuda13-0.1.52` 目录，再从下面检查继续；不要仅凭目录同名就认定版本正确。

```powershell
foreach ($rel in @('strata.py', 'setup.py', 'python/python.exe', 'bin/strata.cmd')) {
    if (-not (Test-Path -LiteralPath (Join-Path $Control $rel))) { throw "Control 缺少：$rel" }
}
if (-not (Test-Path -LiteralPath (Join-Path $dir 'engine-component.json'))) {
    throw '引擎目录结构不对：应直接包含 engine-component.json。'
}

$env:STRATA_INSTALL_DIR = $Control
$env:STRATA_COMPONENTS_DIR = Join-Path $Data 'components32'
$env:STRATA_SETTINGS_FILE = Join-Path $Data 'state/settings.json'
$env:STRATA_PROFILE_DIR = Join-Path $Data 'state/profiles'
$env:STRATA_RUNTIME_DIR = Join-Path $Data 'state/runtime'
$env:STRATA_LAUNCH_PRESET_DIR = Join-Path $Data 'state/presets'
$env:STRATA_REQUIRE_SIGNED_COMPONENTS = '1'
New-Item -ItemType Directory -Path (Join-Path $Data 'state') -Force | Out-Null

& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') doctor --components
if ($LASTEXITCODE -ne 0) { throw 'doctor 未通过，请先排查，不要启动。' }
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') components engine --full
if ($LASTEXITCODE -ne 0) { throw '引擎签名、文件、驱动或兼容性检查未通过。' }
```

SHA256 只说明文件字节与预期相同，**不代替组件签名及逐文件校验**。上面开启签名要求，不绕过失败，不从不明网站补 DLL。包已包含所需 CUDA 运行库/cuBLAS；仍必须有兼容的 NVIDIA 驱动。

## 3. 从两个分片准备本地 pack

先完成上一章的两个 GGUF 校验，再执行：

```powershell
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') install -- `
    --family coder --model IQ1_M `
    --gguf-dir (Join-Path $Model 'IQ1_M') --data-dir $Model `
    --context 32768 --kv q4_0 --vision no --mtp off `
    --cuda 13 --low-ram mmap --vram-reserve-mib 1792 `
    --parallel 1 --port 18791 --host 127.0.0.1 --no-browser --no-start
if ($LASTEXITCODE -ne 0) { throw '模型准备失败，请保留输出排查。' }
```

- `--gguf-dir` 复用已下载的完整分片；不使用 `--move-data`，不迁移已有模型。
- `--no-start` **只准备，不加载推理模型**；需要磁盘空间和时间，不要误认为卡死。
- `--vision no` 不准备视觉模型；`--mtp off` 避免额外 drafter 下载。
- Control 安装模式调用其内置准备工具，不要求全局 Python/pip，不在此处安装 engine。
- 它会提取/准备 `packs/coder-iq1_m`、tokenizer、专家 profile 及运行配置。`experts.bin` 是从权重生成的本地文件，不是第三个需要手工下载的模型。
- 本文用到的参数已核对 Control 的 help/源码，但**没有在本轮完整重做新机 pack 安装**。命令失败时不要修改哈希、关闭签名或靠猜文件名补文件。

## 4. 先预览，再启动 32K

加载前自行关闭不需要的高占用应用，确保内存/显存足够。不自动结束浏览器、游戏、桌面版 OpenCode 或 Ollama；如果另一个模型仍驻留，先用它自己的正常停止方式释放资源。

```powershell
& nvidia-smi
[math]::Round((Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory / 1MB, 1)
# 上一行约为可用 GiB；建议至少 16，不能据此保证一定能加载。

$opts = @(
    'launch', '--family', 'coder', '--model', 'IQ1_M',
    '--model-path', (Join-Path $Model 'IQ1_M/Qwen3.8-Flash-Next-GSQ-RCO-IQ1_M-00001-of-00002.gguf'),
    '--data-dir', $Model, '--context', '32k', '--parallel', '1',
    '--vision', 'off', '--mtp', 'off', '--drafting', 'off', '--kv', 'q4_0',
    '--access', 'local', '--port', '18791', '--tune', 'skip',
    '--set', 'vram-reserve-mib=1792', '--set', 'resident-experts=off',
    '--set', 'mmap-experts=on', '--set', 'prefill=128',
    '--set', 'prompt-cache=1', '--set', 'conversation-cache-mib=0',
    '--save-preset', 'ctf32', '--no-tui'
)
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') @opts --plan
if ($LASTEXITCODE -ne 0) { throw '启动计划检查失败。' }
# 看清计划中的模型、引擎、路径和端口，确认无意外下载，再执行：
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') @opts
if ($LASTEXITCODE -ne 0) { throw '启动失败，请保留本轮输出。' }
```

只监听 **`127.0.0.1:18791`**；`8080` 留给 Burp Suite。不要加 `--restart` 抢占不明进程，不要开放 `0.0.0.0`、LAN 或隧道。

这些是**基础参数参考**，不是作者旧运行链的完整复刻：13 CPU workers、14GiB 工作集/100ms 守护、Job 限额、加载保护及长任务取消/恢复管理尚未整体移植。不要把一个 JSON 或上述命令当成已具备全部保护的发行版。

## 5. 如何看状态和停止？

在保留上述路径/环境变量的终端执行：

```powershell
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') launch --status
& nvidia-smi

# 只停止本指南创建的 ctf32，不使用 taskkill 去杀全部模型进程。
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') launch --preset ctf32 --stop
if ($LASTEXITCODE -ne 0) { throw '未确认正常停止，请检查状态，不要启动第二个引擎。' }
```

退出 OpenCode TUI **不等于**卸载模型。先在 TUI 取消生成并退出，再用上面命令停止引擎；最后检查状态及显存。重新开终端后需要重设路径/环境变量，不要将这些配置写入全局 `setx`。

## 6. 64K 候选：可选，不作为首次部署默认

先通过 32K 的首次连接测试并停止 `ctf32`。下载 64K 引擎：

```powershell
fetch $cfg.candidate.url (Join-Path $Cache $cfg.candidate.file) $cfg.candidate.sha256 $cfg.candidate.bytes
$dir = Join-Path $Data 'components64/engine/cuda13-0.1.59'
if (Test-Path -LiteralPath $dir) { throw '候选引擎目录已存在，请核对后复用，不要覆盖。' }
New-Item -ItemType Directory -Path $dir -Force | Out-Null
& tar.exe -xzf (Join-Path $Cache $cfg.candidate.file) -C $dir
if ($LASTEXITCODE -ne 0) { throw '候选引擎解压失败。' }
if ((Get-FileHash -LiteralPath (Join-Path $dir 'engine-component.json') -Algorithm SHA256).Hash -ne $cfg.candidate.manifest_sha256) {
    throw '候选引擎 manifest 哈希不符。'
}
$env:STRATA_COMPONENTS_DIR = Join-Path $Data 'components64'
& (Join-Path $Control 'python/python.exe') (Join-Path $Control 'strata.py') components engine --full
if ($LASTEXITCODE -ne 0) { throw '候选引擎校验未通过。' }
```

0.1.59 压缩包内是平铺文件，`engine-component.json` 应直接在 `$dir` 下。manifest build 为 `712fec6b4297+cuda13.0`，要求 NVIDIA driver 至少 `580.65`。

要试 64K，在第 4 节 `$opts` 中把 `32k` 改为 `64k`、`ctf32` 改为 `ctf64`，保持其余保护和参数，再分别执行预览及启动。OpenCode 的软窗口也须另改，详见下一章；**仅改 Agent 的 context 数字不会扩展引擎窗口**。停止命令相应使用 `launch --preset ctf64 --stop`。

现有作者环境额外使用过以下候选环境变量，供后续复现研究，不代表基础命令已完整验证长任务：

```powershell
$env:STRATA_HC_Q8 = '1'
$env:STRATA_HC_Q8_INJECT = '0'
$env:STRATA_HC_REQ8 = '0'
$env:STRATA_PCIE_START = 'old'
$env:STRATA_LOOKUP_MAX_T = '0'
```

回退：先停止 `ctf64`，将组件目录改回 `components32`，取消上面五个候选变量，使用原来的 `32k`/`ctf32` 参数及 24K OpenCode 软窗口重新启动。**不要并行加载两套模型，也不要覆盖 32K 引擎目录。**

64K 的有限测试不能替代全新机器验收；若长预读、显存不足、系统换页或缓存失效，先回到 32K，不要降低安全预留硬挤。
