## 2. 准备自己的路径

在 **CTFCode 源码根目录**打开一个新的 PowerShell。以下命令只改变当前终端变量；不用管理员、不使用 `setx`。

```powershell
$ErrorActionPreference = 'Stop'
$Repo = (Get-Location).Path
if (-not (Test-Path -LiteralPath (Join-Path $Repo 'config/models/gsq-rco-coder-iq1-m.json'))) {
    throw '请先进入 CTFCode 源码根目录。'
}

# 下载前改到空间充足的 SSD 目录；不要选盘根或已有其他软件目录。
$Data = Join-Path $env:LOCALAPPDATA 'CTFCode'
$Model = Join-Path $Data 'models/GSQ-RCO-Coder'
$Cache = Join-Path $Data 'downloads'
$Control = Join-Path $Data 'runtime/control-0.1.52'
New-Item -ItemType Directory -Path $Model, $Cache -Force | Out-Null
```

如果已经有这两个文件，**把 `$Model` 改为它们的上级模型目录**（内部应有 `IQ1_M` 子目录），再执行校验即可。不要复制几十 GB 数据到源码目录。

## 3. 直连、断点续传和校验

下面的 `fetch` 是文档中临时定义的 PowerShell 函数，不会安装任何脚本入口。它跳过已完整且哈希正确的文件；短文件尝试续传；大小异常或哈希不符则停止，**不删除原文件**。

```powershell
function fetch($url, $file, $sha, $bytes) {
    if (Test-Path -LiteralPath $file) {
        if ((Get-Item -LiteralPath $file).Length -eq $bytes) {
            if ((Get-FileHash -LiteralPath $file -Algorithm SHA256).Hash -ne $sha) {
                throw "已有文件哈希不符，请保留排查，不要继续使用：$file"
            }
            Write-Host "已校验，跳过：$file"
            return
        }
        if ((Get-Item -LiteralPath $file).Length -gt $bytes) {
            throw "已有文件大小异常，请保留排查：$file"
        }
    }
    New-Item -ItemType Directory -Path (Split-Path -Parent $file) -Force | Out-Null
    & curl.exe --noproxy '*' --location --fail --continue-at - `
        --connect-timeout 20 --retry 2 --retry-delay 3 --output $file $url
    if ($LASTEXITCODE -ne 0) { throw "下载未完成，可稍后重新执行以续传：$file" }
    if ((Get-Item -LiteralPath $file).Length -ne $bytes) { throw "大小不符：$file" }
    if ((Get-FileHash -LiteralPath $file -Algorithm SHA256).Hash -ne $sha) {
        throw "SHA256 不符，请保留文件排查，不得启动模型：$file"
    }
    Write-Host "下载并校验通过：$file"
}

$cfg = Get-Content -LiteralPath (Join-Path $Repo 'config/models/gsq-rco-coder-iq1-m.json') -Raw -Encoding UTF8 | ConvertFrom-Json
foreach ($file in $cfg.files) {
    fetch $file.url (Join-Path $Model $file.path) $file.sha256 $file.bytes
}
```

官方直连不可用时，保留同一 `fetch` 函数和 `$cfg`，改执行下列循环，走 **国内镜像直连**：

```powershell
foreach ($file in $cfg.files) {
    fetch $file.mirror (Join-Path $Model $file.path) $file.sha256 $file.bytes
}
```

`--noproxy '*'` 绕过 curl 使用的代理配置，不读取 Clash 的 HTTP/SOCKS 代理；**如果启用了 Clash TUN/透明代理，它不能绕过系统路由接管**，需自行关闭 TUN 或添加直连规则，才能保证真正直连。不要加 `--insecure` / `-k`。

## 4. 常见下载问题

- **只有一个分片**：不能用；继续下载另一个，不要自行合并。
- **下载得到很小的 HTML/文本文件**：很可能是错误页或 Git LFS 指针；大小与 SHA256 不会通过。
- **HTTP 416**：完整文件本应被校验后跳过。检查大小/哈希；不要盲目删除模型或继续追加。
- **不支持断点续传**：保留部分文件，换一个新的目标文件名完整下载并核验后，再手动替换；不要让客户端覆盖不明来源的旧文件。
- **哈希不符**：先停止。核对量化、revision、文件名及下载源；镜像哈希不能替代独立的预期哈希。
- **校验慢**：完整 SHA256 会读取约 58.4GB，这是磁盘校验，不是模型推理。

两个 GGUF 校验通过后，还需下一章的 **pack/tokenizer 准备**。不能只放两个权重文件就声称 Strata 已可运行。
